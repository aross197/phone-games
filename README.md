# Phone Games

A clean, mobile-first collection of classic HTML5 games that work great on phones. No installs, no accounts, no ads.

## Games included

- **Snake** – Swipe to control
- **2048** – Swipe to merge tiles
- **Pong** – Touch/drag to move the paddle
- **Memory** – Match the pairs

## Play it

Open the site on your phone:

**https://aross197.github.io/phone-games/**

(Once GitHub Pages is enabled – see below)

## Enable GitHub Pages

1. Go to the repository **Settings → Pages**
2. Under “Source”, select **Deploy from a branch**
3. Choose branch `main` and folder `/ (root)`
4. Save – the site will be live in a minute or two at the link above.

## Tech

Pure HTML, CSS and vanilla JavaScript. No frameworks, no build step.

Made to be simple, fast, and actually enjoyable on a phone.
